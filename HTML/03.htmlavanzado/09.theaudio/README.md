# The Audio

## Elements

- `<audio>` = The audio element represents a sound.
- `<source>` = The source element specifies multiple media resources for the `<audio>` element.

## Attributes

- `autoplay` = Specifies that the sound should start playing as soon as the page loads.
- `controls` = Specifies that the user should get some control over the media element.
- `src` = The src attribute specifies the URL of the audio file.

## JavaScript

- `onClick` = The onClick attribute specifies a script to be run when the user clicks the audio player.
- `getElementById()` = The getElementById() method returns the element that has the ID attribute with the specified value.
- `play()` = The play() method plays the audio.
- `pause()` = The pause() method pauses the audio.
- `volume` = The volume attribute specifies the volume of the audio.
