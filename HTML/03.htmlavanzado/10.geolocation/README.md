# GEOLOCATION

## Elements

- `<div>` = Will be the container for the map
- `<script>` = Will be the script for the map

## JavaScript

- `navigator.geolocation` = This represents the geolocation API, which is a way to get the user's location.
- `innerHTML` = Allow to change the content of the element
- `position.coords` = This gives us the latitude and longitude of the user
- `src` = This is the source of the map
- `async defer` = This is used to load the map asynchronously.
- `initMap` = This is the function that will be called when the map is loaded
- `showPosition` = This is the function that will be called when the user's location is found
- `google.maps.Map` = This is the class that will be used to create the map
- `center` = This is the center of the map. It is an object with the latitude and longitude of the user
- `navigator.geolocation.getCurrentPosition` = This is the function that will be called when the user's location is found
