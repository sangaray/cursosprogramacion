# INTERACTIONS

## Functional Patterns

It is a pattern that allows you to create a function that performs a specific task.

**Various Events**

- `Drag` = It allows to drag an element.
- `Drop` = It allows to drop an element.

## HTML

**Attributes**

- `ondrop` = It is used to specify the code to be executed when an element is dropped on the target element.
- `ondragover` = It is used to specify the code to be executed when an element is being dragged over the target element.
- `ondragstart` = It is used to specify the code to be executed when an element is being dragged.
- `drag` = It is used to specify the code to be executed when an element is being dragged. - `draggable` = It indicate that an element can be dragged.

## JavaScript

**Methods**º

- `appendChild` = It is used to add a child element to a parent element.
- `dataTransfer` = It is used to get the data that is being dragged.
- `setData` = It is used to set the data that is being dragged.
- `target` = It is used to get the element that is being dragged.
- `prenvetDefault` = It is used to prevent the default behavior of an event.
