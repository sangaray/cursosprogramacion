# SEO

It is a way to help the positioning of the page in the search engine

SEO = Search Engine Optimization

It allows to process an rise the amount of trafico to the page

## Take in account

- Web content
- Internal structure

## Elements

- `<title> ` = Get the search engine understandin what is our web site about. It is the name of your company or service. It is show in the the list of the search engine or search page. In our web page it appears in the title bar or in the tab. Is important to use key words or words related to your company or service and ths differenciate yours web page from other web pages. It never should be empty.
- `<meta>` = Metadata is a list of data that is not visible to the user. It is important because the search engine can use this data to show the results in the language that the user is using.
- `<h1 to 6>` = They indicate the importance level of the content. They are used to show the hierarchy of the content. They are show in the search engine.
  - `<h1>` = usually reserve for the titles on the web page
  - `<h2>`= highlight the subject of the title
  - `<h3>`= signals th points related to the subject
  - `<h4>` = Accepts points from the `h3`
  - `<h5>`= Is not frequently used
  - `<h6>`= Is not frequently used

**Attributes**

- `lang` = It tells to the search engine what language is the web page. It is important because the search engine can show the results in the language that the user is using.
- `content`= Is the content of the metadata related to the type of it used
- `name` = It is the name of the metadata. It is used to identify the metadata.

**Values del name**

- `keywords` = They are the key words of the web page, they shows what the web page do or is about
- `description` = It is a text shown in the search engine as a description of the web page.

## Links

- `<a>` = Link element. It is used to create links to other web resources.

**Attributes**

- `rel` = It is the relationship between the current page and the linked page.
- `href` = It is the URL of the linked page.

**Values**

- `nofollow` = Prevents the search engine from following or knowing the linked page.

## Canonical Links

This means different ways to write a link or use the same link.

- `http` = This protocol is used to send the data that is sent between the web server and the client but it is not encrypted and currenly it is no recomended.
- `https` = This protocol is used to encrypt the data that is sent between the web server and the client. It is important because the data is not visible to the user.
  - http://www.google.com
  - https://www.google.com
  - https://google.com
  - https://www.google.bo
