# Multiple Columns

It means that the text is divided into columns. It is used to create a layout with multiple columns.

## CSS Properties

- `column-count` = It is used to specify the number of columns in a multi-column layout.
- `column-gap` = It is used to specify the space between thecolumns in a multi-column layout.
- `column-rule` = It is a shorthand property that allows you to specify the style and width of the rule between the columns in a multi-column layout.
- `column-rule-style` = It is used to specify the style of the rule between the columns in a multi-column layout.

  **Values**
  - `none` = It is used to specify that there is no rule between the columns in a multi-column layout.
  - `solid` = It is used to specify that the rule between the columns in a multi-column layout is solid.
  - `double` = It is used to specify that the rule between the columns in a multi-column layout is double.
  - `dotted` = It is used to specify that the rule between the columns in a multi-column layout is dotted.
  - `dashed` = It is used to specify that the rule between the columns in a multi-column layout is dashed.
  - `groove` = It is used to specify that the rule between the columns in a multi-column layout is groove.
  - `ridge` = It is used to specify that the rule between the columns in a multi-column layout is ridge.
  - `inset` = It is used to specify that the rule between the columns in a multi-column layout is inset.
  - `outset` = It is used to specify that the rule between the columns in a multi-column layout is outset.

- `column-rule-width` = It is used to specify the width of the rule between the columns in a multi-column layout.
- `column-rule-color` = It is used to specify the color of the rule between the columns in a multi-column layout.
- `column-span` = It is used to specify the number of columns that a particular element should span in a multi-column layout.
