# 3D Transformation

## CSS Properties

- `z-index` = it determines the elements order in the x axis of the piling context. The higher the value, the higher the element. The default value is 0. It is used to create that piling context.
- `position` = this property is used to create that piling context. It allows to position the element in the piling context.

  **Values**
  - `relative` = The element is positioned relative to its normal position.
  - `absolute` = The element is positioned relative to the viewport.

- `perspective` = it allows to create a 3D effect giving the illusion of depth.
- `transform-style` = it allows to create a 3D effect giving the illusion of depth.

  **Values**
  - `preserve-3d` = it allows to create a 3D effect giving the illusion of depth.
  - `flat` = this value is the default value.

- `transform` = this property allows to apply to the element different kind of movements

  **Values**
  - `translateX` = it allows to move the element in the x axis.
  - `translateY` = it allows to move the element in the y axis.
  - `translateZ` = it allows to move the element in the z axis.
  - `rotate` = it allows to rotate the element.
  - `rotateX` = it allows to rotate the element in the x axis.
  - `rotateY` = it allows to rotate the element in the y axis.
  - `rotateZ` = it allows to rotate the element in the z axis.
  - `scale` = it allows to scale the element.
  - `scaleX` = it allows to scale the element in the x axis.
  - `scaleY` = it allows to scale the element in the y axis.
  - `scaleZ` = it allows to scale the element in the z axis.
  - `skew` = it allows to skew the element.
  - `skewX` = it allows to skew the element in the x axis.
  - `skewY` = it allows to skew the element in the y axis.

**Pseudo-selectors**

- `nth-child` = it allows to select the element that is the nth child of its parent element. It is used to create that piling context.
