# Spacing

There are two types of spacing in CSS:

- Internal Spacing = The spacing between the content and the border of an element, am internal border.
- External Spacing = The spacing between the border and the margin of an element. Used to separate boxes or elements, an external border.images

**CSS Properties**

- `margin` = It is used to add space outside the element.
- `padding` = It is used to add space inside the element.
- `margin-inline-start` = It is used to add space to the left of the element.
- `margin-inline-end` = It is used to add space to the right of the element.
- `margin-block-start` = It is used to add space to the top of the element.
- `margin-block-end` = It is used to add space to the bottom of the element.
- `margin-top` = It is used to add space to the top of the element.
- `margin-right` = It is used to add space to the right of the element.
- `margin-bottom` = It is used to add space to the bottom of the element.
- `margin-left` = It is used to add space to the left of the element.
