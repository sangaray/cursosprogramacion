# Information Tools

## CSS Properties

- `content` = The content property specifies the content of an element. It is used to insert text or HTML into an element.
- `visibility` = The visibility property specifies whether an element is visible or hidden. It can be used to hide an element from the user.

  **Values**
  - `visible` = The element is visible.
  - `hidden` = The element is hidden.

- `border-color`= The border-color property is used to specify the color of the border of an element. It can be set to any valid color value, such as a named color, a hexadecimal value, or a RGB value.

  **Values**
  - `transparent` = The border is transparent.

## Psudo Selector

- `::after` = The ::after pseudo-selector is used to insert content after the content of an element.
