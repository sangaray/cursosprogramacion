# Borders Part One

## CSS Properties

- `display` = Indicate how an element is displayed.

  **Values**
  - `flex` = The element is displayed as a flex container. A flex container is a block-level element that can contain flex items, which can be inline elements or other block-level elements. It is used to create flexible and responsive layouts.

- `justifify-content` = Indicate the alignment of flex items along the main axis of a flex container.

  **Values**
  - `space-between` = The flex items are distributed evenly across the flex container, with equal spacing between them.

- `flex-wrap` = Indicate whether flex items should wrap or not. It means that if the flex items do not fit in the flex container, they will be wrapped onto multiple lines.

  **Values**
  - `wrap` = The flex items will wrap onto multiple lines if necessary.

- `border-radius` = It gives the element a rounded border or vertices.
- `background-color` = It gives the element a background color.
- `padding` = It is used to add space inside the element.
- `width` = It is used to set the width of the element. It means the horizontal size
- `height` = It is used to set the height of the element. It means the vertical size
- `background-image` = It is used to add an image as the background of the element.

  **Values**
  - `url` = It gives the path to the image.

- `background-position` = It is used to position the background image in the element.

  **Values**
  - `left` = It positions the background image to the left of the element. From the upper left corner.

- `background-repeat` = It is used to repeat the background image in the element if it is smaller than the element.

  **Values**
  - `repeat` = It repeats the background image in the element if it is smaller than the element.
