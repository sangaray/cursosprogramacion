# Styles in Images

## CSS Properties

- `opacity` = The opacity property sets the transparency of an element. The value must be a number between 0 and 1, where 0 is fully transparent, and 1 is fully opaque.
- `backface-visibility` = The backface-visibility property specifies whether the back face of an element should be visible when facing the user. It can be used to create a 3D effect.
