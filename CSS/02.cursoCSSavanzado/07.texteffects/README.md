# Text Effect

## CSS Properties

- `writing-mode` = The writing-mode property specifies whether the text is written horizontally or vertically, or both.

  **Values**
  - `horizontal-tb` = The text is written from left to right and top to bottom.
  - `vertical-rl` = The text is written from top to bottom and right to left.
  - `vertical-lr` = The text is written from top to bottom and left to right.

- `word-wrap` = The word-wrap property specifies whether to break words when they reach the edge of their container.

  **Values**
  - `break-word` = The words will break if they reach the edge of their container.

- `text-overflow` = The text-overflow property specifies how hidden overflow content is displayed.

  **Values**
  - `ellipsis` = The text will be displayed as ellipsis (...).

- `overflow` = The overflow property specifies what happens if content overflows an element's box.

  **Values**
  - `hidden` = The overflow is clipped, and the rest of the content will be invisible.

- `resize` = The resize property specifies whether the user can resize an element.

  **Values**
  - `horizontal` = The user can resize the element horizontally.
