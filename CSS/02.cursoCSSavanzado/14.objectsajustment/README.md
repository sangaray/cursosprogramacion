# Objects Ajustment

## CSS Properties

- `object-fit` = property than defines how an element responds to the width and height of its content box or container.

  **Values**
  - `cover` = the image will fill the height and width of the content box, once more keeping its aspect ratio, but often clipping the image in the process.
  - `contain` = sizing up or down the image size to fit the content box keeping its aspect ratio. -`none` = the image will ignores the parent element widht and height and will keep its original size.
  - `fill` = this is the default value, it will expand the image to fit the content box, but independenty of it aspect ratio.
