# Animations

## CSS Properties

- `animation` = states the name of the @keyframes animation to use.
- `animation-name` = states the name of the @keyframes animation to use.
- `animation-duration` = indicates the time than takes to the animation in complete a cycle.
- `animation-timing-function` = is the aceleration prestablished.
- `animation-delay` = is the time between the charge of the elements y the momemt when the animation starts.
- `animation-direction` = stablishes the direction of the animation after the cycle.
- `animation-iteration-count` = is the number of time the animation is repeated.
- `animation-fill-mode` = stablishes the values applied before and after the animation.
- `animation-play-state` = play the animation.
