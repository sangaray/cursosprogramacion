# Gradients

## CSS Properties

- `linear-gradient` = Sets a linear gradient on an element.
- `repeating-linear-gradient` = Sets a repeating linear gradient on an element.
- `radial-gradient` = Sets a radial gradient on an element.
- `repeating-radial-gradient` = Sets a repeating radial gradient on an element.

**Structure**

- `linear-gradient(direction, color-stop-list)`
- `repeating-linear-gradient(direction, color-stop-list)`
- `radial-gradient(shape, size, color-stop-list)`
- `repeating-radial-gradient(shape, size, color-stop-list)`
