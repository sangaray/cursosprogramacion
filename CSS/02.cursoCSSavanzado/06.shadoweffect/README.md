# Shadow Effect

## CSS Properties

- `text-shadow` = The text-shadow property applies one or more shadows to text.

  **Structure**
  - One shadow -`text-shadow: h-shadow v-shadow blur-radius color;`
  - Multiple shadows can be specified using commas. -`text-shadow: h-shadow v-shadow blur-radius color, h-shadow v-shadow blur-radius color;`

- `box-shadow` = The box-shadow property applies one or more shadows to an element.

  **Structure**
  - One Shadow -`box-shadow: h-shadow v-shadow blur-radius spread-radius color;`
  - Multiple shadows can be specified using commas. -`box-shadow: h-shadow v-shadow blur-radius spread-radius color, h-shadow v-shadow blur-radius spread-radius color;`
