# Transformacion 2D

## CSS Properties

- `transform` = The transform property is a shorthand property for the transform-origin, transform-style, and transform properties.

  **Values**
  - `translate` = The translate property moves an element in the horizontal or vertical direction.
  - `rotate` = The rotate property rotates an element to right or left.
  - `scale` = The scale property scales an element. It horizontally and vertically.
  - `skew` = The skew property skews an element. It horizontally and vertically. To right or left.

- `animation` = The animation property is a shorthand property for the animation-name, animation-duration, animation-timing-function, and animation-delay properties.

  **Structure**
  - `animation: animation-name animation-duration animation-timing-function animation-delay;`

- `animation-direction` = The animation-direction property specifies the direction of the animation.

  **Values**
  - `alternate` = The animation will alternate between normal and reverse directions.

- `@keyframes` = The @keyframes at-rule is used to define a set of style rules that are to be applied over a given time interval.

  **Structure**
  - `@keyframes name { from { ... } to { ... } }`
