# Transitions

## CSS Properties

- `transition-timing-function` = The transition-timing-function property specifies the speed curve of the transition effect.

  **Values**
  - `ease` = specifies a transition effect with a slow start, then fast, then end slowly.
  - `linear` = specifies a transition effect with the same speed from start to end.
  - `ease-in` = slowly start
  - `ease-out` = fastly end

## Animations

- `animation` = The animation property is a shorthand property for the animation-name, animation-duration, animation-timing-function, and animation-delay properties.
- `animation-delay` = The animation-delay property specifies the amount of time to wait before starting an animation.
