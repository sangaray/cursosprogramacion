# Borders Part Two

## CSS Properties

- `border-image` = Sets an image to be used instead of the border style. It will appear in the corners of the element
- `borde-image-slice` = It is allows to slice the image to fit the element border
- `border-image-width` = It is used to set the width of the element border
- `border-image-outset` = It is used to set the distance between the element border and the image
- `border-image-repeat` = It is used to set the repeat of the image in the element border
