# Logical Functions

Controls the size of an element and keep the adecuate space to implement a fluid typography.

- `min()` = The min() function returns the smallest value between two or more values.
- `max()` = The max() function returns the largest value between two or more values.
- `clamp()` = The clamp() function returns a value within a range.

## CSS min() function

**exemple**

- `width: min(50%, 400px);`
- `width: max(50%, 400px);`
- `width: clamp(350px,50%, 500px);`
