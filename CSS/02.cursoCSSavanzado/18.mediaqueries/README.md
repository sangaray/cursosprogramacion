# Media Queries

It is a CSS3 function that allowe to a web page to have an adaptable design to different screen sizes or medios. Getting a responsive web design.

## Screen Size

- 320px - 480px = movile device
- 481px - 768px = tablet
- 769px - 1024px = notebook
- 1025px - 1200px = desktop
- 1201px + = big screen and TV

## Media Queries Actions

- all = all kind of medios
- print = for printers
- screen = for screen
- speech = for screen readers, which reads the page out loud
